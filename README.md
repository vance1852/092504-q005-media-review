# 数字作品评审协作服务

本项目为数字交互媒体设计训练提供**不渲染媒体内容**的作品评审后台。系统只登记作品的
摘要与元数据（脚本摘要、素材清单、交互说明、作者声明、交付清单、版权凭据摘要），
在此基础上完成版本登记、截止冻结、评委回避分派、评分、申诉与审计。

同时保留原有的机构、操作者、场所与领域资料统一登记能力，支持请求幂等、角色权限、
SQLite 事务与哈希串联审计。

## 核心规则

- **只追加的提交版本**：截止前允许为同一作品追加新版本；同名压缩包以内容摘要
  （`content_digest`）区分；任何旧版本都没有改写路径，重复内容摘要直接拒绝。
- **截止冻结送审快照**：到截止时间后冻结赛事，每个作品只取其最新版本进入快照；
  缺少必要版权凭据（许可为 `licensed`/`permission` 却无凭据摘要，或许可为 `unknown`）
  的作品只能进入 `pending_evidence` 状态，不参与分派、不能被评分。
- **回避分派**：分派时排除存在利益冲突登记、与作者同组织、已主动回避或已在任的评委，
  按当前工作量均衡选择；符合回避规则的评委不足时直接报错而不降低回避标准。
- **评分引用具体版本**：评分必须引用冻结快照中的 `submission_id`（连同版本号与内容摘要
  一并写入审计），引用旧版本会被拒绝。
- **决定不可改写**：同一 `request_id` 的重复评分返回原决定（`replayed=true`）；
  不同分值复用同一请求编号返回 409 冲突；换新请求号也无法改写既有决定。
- **申诉双轨留痕**：申诉期间原分与复核分都保留；原审评委、同组织评委、有冲突或已回避的
  评委不能复核；裁决按赛事容差（`score_tolerance`）比较复核均分与原审均分——
  差值在容差内维持原分（`original_upheld`），超出则采用复核分（`review_applied`）。
- **两类查询**：公开查询只展示脱敏汇总（化名、版本摘要、分数均值与状态，不含作者、评委、
  评语）；审计查询仅 admin/auditor 可用，可追到每个版本的素材凭据、回避与分派记录、
  每次评分/复核决定及其请求编号，并汇总相关哈希审计事件。

## 目录

- `src/skills_workspace/`
  - `service.py`：机构、操作者、场所与领域资料登记；
  - `review.py`：作品评审后台（赛事、只追加版本、冻结、回避分派、评分、申诉、公开/审计查询）；
  - `storage.py`：SQLite 连接、建表与事务边界；
  - `audit.py`：可离线校验的哈希串联审计日志；
  - `api.py`：仅依赖标准库的 HTTP/JSON 路由；
  - `acceptance.py`：覆盖基础链与完整评审链的离线端到端验收。
- `tests/`：核心规则、事务边界、接口路由和端到端验收测试。

## 环境

- Linux
- Python 3.11 或更高版本
- 运行时仅使用 Python 标准库和 SQLite

```

```

## 离线验收

```bash
PYTHONPATH=src python3 -m skills_workspace.acceptance
```

命令会在临时 SQLite 数据库中走通：基础登记链 → 赛事/作品登记 → 同名压缩包两轮只追加
提交 → 截止冻结（含待补证作品）→ 利益冲突排除与分派 → 不可改写评分与幂等重放 →
申诉复核与容差裁决 → 公开脱敏与审计全链路查询，核对幂等回执与审计链。成功时输出一行
`status` 为 `ok` 的 JSON 并以退出码 `0` 结束。

## HTTP 服务

```bash
PYTHONPATH=src python3 -m skills_workspace.api --database skills_workspace.sqlite3 --host 127.0.0.1 --port 8080
```

健康检查使用 `GET /health`。所有写接口通过 `X-Actor-Id` 标识操作者，并用 `request_id`
实现幂等；重放返回 200，新建返回 201，同号不同内容返回 409。

作品评审后台接口（均为 `POST`，除查询外）：

| 路径 | 说明 |
| --- | --- |
| `/competitions` | 登记赛事（截止时间、每作品评委数、容差、评分维度表） |
| `/competitions/freeze` | 到截止时间后冻结送审快照 |
| `/works` | 登记作品（作者、化名） |
| `/submissions` | 追加提交版本（摘要/素材清单/交互说明/作者声明/交付清单） |
| `/conflicts` | 登记评委对作品的利益冲突（评委可自行登记回避） |
| `/assignments` | 按回避规则分派评委（可重复调用为回避空缺补员） |
| `/assignments/recuse` | 评委主动回避已分派任务 |
| `/scores` | 提交评分（必须引用冻结的 `submission_id`） |
| `/appeals` | 作者提起申诉 |
| `/appeals/reviews` | 非原审、无冲突评委提交复核分（同样引用冻结版本） |
| `/appeals/rule` | 按容差规则裁决，生成最终结果 |
| `GET /works/{id}/public` | 公开脱敏汇总（无需身份） |
| `GET /works/{id}/audit` | 审计全链路（仅 admin/auditor） |

服务重启后，SQLite 中的业务状态和审计链继续保留。
